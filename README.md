# Terminal HR Solution App

A simple terminal-based HR application that supports:

- Employee management
- Attendance tracking
- Payroll report generation for date ranges

## Run

```bash
python3 hr_app.py
```

## Features

1. **Add employee** with an ID, name, and hourly rate.
2. **List employees** currently in the system.
3. **Mark attendance** with date and hours worked.
4. **View attendance** records.
5. **Generate payroll report** between start and end dates.

## Data Storage

The app persists data in `hr_data.json` in the project root.
